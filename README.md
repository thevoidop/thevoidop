### 👤 The Human Behind the Screen

I'm a full-stack engineer and machine learning practitioner who genuinely enjoys building complex systems from scratch. When I'm not writing clean code, I'm usually figuring out why the thing I built yesterday suddenly decided to stop working today. My work sits at the intersection of **low-level backend architecture**, **client-side web processing** and **Natural Language Processing (NLP)**.

- 🏗️ **Systems & Backend:** I like bypassing high-level abstractions. I build non-blocking HTTP servers from scratch, manage raw TCP sockets and engineer zero-dependency media streaming pipelines.
- 🧠 **AI & ML:** Deeply focused on NLP, Parameter-Efficient Fine-Tuning (LoRA) and bridging the gap between human languages and intelligent computation.
- ⚡ **Web Engineering:** Shipping heavily optimized, privacy-first web suites utilizing native browser APIs and advanced client-side processing to keep data strictly secure.

---

### 🚀 What I've Been Building

- 📝 **[DocDash](https://docdash.site)** — A privacy-first Next.js web suite for image/PDF manipulation utilizing native browser APIs (100% client-side).
- 🎬 **[StreamCore](https://github.com/thevoidop/StreamCore)** — A zero-dependency video streaming system utilizing a custom Python HTTP backend and the MediaSource API.
- 🌐 **[serv](https://github.com/thevoidop/serv)** — A non-blocking HTTP/1.1 server built from scratch in under 500 lines of Python using raw TCP sockets and event-driven I/O.
